### A. Sistem POS dengan Prediksi Demand & Optimasi Stok
Deskripsi: Web app kasir untuk UMKM dengan ML prediksi permintaan produk

- Manajemen transaksi penjualan
- Manajemen inventaris real-time
- Dashboard analytics penjualan
- Notifikasi stok menipis
- Laporan keuangan otomatis

Komponen ML:
- Time Series Forecasting untuk prediksi demand (ARIMA, LSTM, Prophet)
- Clustering produk berdasarkan pola penjualan

Dataset: Data transaksi historis (bisa simulasi atau ambil dari UMKM riil)
Dasar Penelitian: Banyak UMKM kesulitan manage stok, sering overstok/understok. 
ML bisa otomasi prediksi kebutuhan.

## REKOMENDASI PEMILIHAN

Kriteria Pilih Ide:
1. Data Availability: Apakah bisa dapat dataset real/simulasi?
2. Complexity Level: Sesuai waktu & skill level?
3. Impact & Novelty: Ada kontribusi baru atau improvement significant?
4. Implementation Feasibility: Tech stack realistic untuk dikerjakan solo/tim kecil?
5. Stakeholder Access: Ada akses ke user/domain expert untuk validasi?

Tech Stack Umum:
- Backend: Laravel/Django/FastAPI
- Frontend: React/Vue/Blade + Tailwind
- ML: Python (scikit-learn, TensorFlow, PyTorch)
- Database: MySQL/PostgreSQL
- Deployment: Docker, AWS/GCP/Azure

Rekomendasi Top 3 untuk TA (balance feasibility & impact):
1. Sistem POS + Demand Forecasting 
   - Clear use case, data bisa simulasi, high business value
   
2. LMS dengan Personalized Learning 
   - Education domain always relevant, banyak dataset public
   
3. Recruitment Platform + Resume Screening 
   - NLP application, clear automation benefit, feasible scope
