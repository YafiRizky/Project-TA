# Dokumentasi Error & Solusi (FLAG 12-06-2026)

Dokumen ini dibuat sebagai referensi untuk mengingat penyebab error yang terjadi selama pengembangan Fase 2 (Multi-Branch/Multi-Tenancy) pada tanggal 12 Juni 2026.

---

## 1. Python `IndentationError: unexpected indent`

**Lokasi:** `pos-backend/accounts/views.py` (pada endpoint `switch_branch` dan `kasir_list_create`)
**Waktu Kejadian:** Saat server Django mencoba melakukan *auto-reload* setelah perubahan file.

### Penyebab:
- Saat melakukan pembaruan massal (menggunakan *automated file replace*) untuk menyuntikkan logika token baru ke dalam `switch_branch`, terjadi tumpang tindih (*overlap*) antara akhir fungsi `switch_branch` dan awal fungsi `kasir_list_create`.
- Deklarasi fungsi `@api_view(['GET', 'POST']) def kasir_list_create(request):` tidak sengaja terhapus, sehingga kode di dalam `kasir_list_create` bergeser dan dianggap sebagai bagian dari blok kode yang ada di atasnya secara tidak teratur.
- Karena Python sangat bergantung pada indentasi (spasi/tab) untuk menentukan blok kode, hilangnya struktur ini langsung memicu `IndentationError: unexpected indent`.

### Solusi:
- Kode dikembalikan strukturnya dengan menuliskan ulang *return response* untuk `switch_branch`, lalu mendeklarasikan ulang fungsi `kasir_list_create(request)` dengan indentasi yang benar di bawahnya.
- **Pelajaran:** Selalu berhati-hati dengan *replace* teks yang memotong bagian tengah antar dua fungsi di Python.

## 2. Vite `Failed to resolve import "lucide-react"`

**Lokasi:** `pos-frontend/src/pages/BusinessSelectionPage.jsx`
**Waktu Kejadian:** Saat Vite mencoba memproses (compile) halaman pemilihan bisnis baru di browser.

### Penyebab:
- Untuk memberikan UI/UX yang modern dan estetis pada halaman `BusinessSelectionPage.jsx`, saya mengimpor ikon-ikon dari *library* `lucide-react` (`import { Store, Plus, Building2, ... } from "lucide-react"`).
- Namun, *library* `lucide-react` sebenarnya belum ter-install di dalam `package.json` proyek POS ini (proyek ini sebelumnya lebih sering menggunakan `react-icons`).
- Saat Vite merender halaman, ia tidak dapat menemukan *package* tersebut di direktori `node_modules`, sehingga memicu `Pre-transform error`.

### Solusi:
- Menjalankan perintah `npm install lucide-react` di dalam direktori `pos-frontend`.
- Hal ini juga mirip dengan error sebelumnya terkait `react-select` dan `react-hot-toast` yang belum terdaftar di dependensi lokal saat diakses.
- **Pelajaran:** Jika menggunakan komponen dari pihak ketiga (3rd party library) yang baru di dalam sebuah *file*, harus selalu dipastikan terlebih dahulu bahwa library tersebut di-install via `npm install`.

---

**Status:** Kedua error telah diperbaiki dan sistem berjalan normal dengan fungsi Multi-Branch.
