# Flow — POS ML System

Folder ini berisi alur/flow sistem POS ML dari perspektif pengguna (Admin & Kasir).

## Isi Folder

| File | Keterangan |
|------|------------|
| `FLOW_ADMIN.md` | Flow lengkap fitur Admin/Owner |
| `FLOW_KASIR.md` | Flow lengkap fitur Kasir |
| `FLOW_SYSTEM.md` | Flow sistem background (FIFO, notif, ML) |
| `flowchart.html` | Diagram visual interaktif semua flow |

## Cara Baca

- Baca file `.md` untuk cerita ringkas dari setiap alur
- Buka `flowchart.html` di browser untuk diagram visual
- Fitur yang **belum diimplementasi** ditandai dengan label `[BELUM]`
- Fitur yang **sudah selesai** ditandai dengan `[OK]`
