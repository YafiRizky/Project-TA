3. PERINTAH (COMMAND) PENTING DI TERMINAL VPS (root@mercatura)
------------------------------------------------------------------------------

1. Update Otomatis Website (Setiap Ada Push Kode Terbaru di GitHub):
   cd /var/www/mercatura-pos && ./update.sh

2. Cek Status Service Backend (Gunicorn) & Web Server (Nginx):
   sudo systemctl status mercatura-backend
   sudo systemctl status nginx

3. Restart Manual Service Backend & Web Server:
   sudo systemctl restart mercatura-backend && sudo systemctl restart nginx

4. Memantau Log Error Real-time (Journalctl):
   journalctl -u mercatura-backend -f

5. Clear Cache Python Bytecode (.pyc):
   cd /var/www/mercatura-pos && find . -name "*.pyc" -delete

6. Regenerasi / Reset Data Simulasi UMKM 1 Tahun:
   cd /var/www/mercatura-pos/pos-backend && source .venv/bin/activate && python manage.py generate_umkm_data

7. Memeriksa Penggunaan RAM & Beban CPU Server:
   free -h && htop
