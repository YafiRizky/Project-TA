ABSTRAK
Alfino Almero Suroso dan Primafadhil Sulistyo “SPOONYCAL : Penghitung Kalori Berbasis Citra 
Makanan Menggunakan Internet of Things (IoT) dan Deep Learning”, Tugas Akhir DIII Program 
Studi Teknik Informatika, Jurusan Teknik Elektro, Politeknik Negeri Semarang, dibawah bimbingan 
Dr. Ir. Kurnianingsih, S.T., M.T. dan Angga Wahyu Wibowo, S.Kom., M.Eng September 2022. 
Kalori yang masuk ke dalam tubuh, harus disesuaikan dengan kebutuhan sehari - hari. Kekurangan 
kalori akan mengakibatkan tubuh lemas dan menurunkan tingkat imun tubuh. Oleh karena itu, 
pentingnya menjaga asupan kalori guna meminimalisir resiko terkena penyakit kronis. Namun dalam 
melakukan kegiatan ini, banyak orang masih merasa kesulitan dalam mengatur asupan kalori yang 
masuk ke dalam tubuh. SPOONYCAL mampu merancang sistem untuk memperingatkan dalam 
mengatur pola makanan pada masyarakat agar lebih terkontrol. Selain itu, sistem juga dapat 
melakukan perhitungan kalori pada makanan secara terintegritas dan personal. Dengan rancangan 
sistem diatas pengguna dapat mengetahui mengetahui total kalori yang dimakan untuk 
Meminimalisir terjadinya penyakit yang diakibatkan oleh kekurangan maupun kelebihan kalori pada 
tubuh. Dalam proses pengembangan sistem digunakan metode yang dilakukan secara berurutan atau 
biasa dikenal dengan metode waterfall. Dari analisis kebutuhan menghasilkan kebutuhan fungsional 
yang digambarkan dalam use case diagram serta hasil perencanaan sistem digambarkan dalam 
activity diagram dan pemodelan basis data. Dalam proses pembuatan sistem, digunakan framework 
Flutter, bahasa pemrograman dart, model deep learning, weight sensor, dan juga database mysql 
untuk penyimpanan data. Berdasarkan hasil pengujian yang meliputi pengujian black box 
menunjukkan seluruh fungsionalitas fitur sistem berjalan dengan baik dan berdasarkan hasil 
kuisioner dari 15 responden yang terdiri atas pengelola serta masyarakat, didapatkan hasil persentase 
kepuasan pengguna sebesar 93,16% dan dapat disimpulkan bahwa sistem sangat memuaskan. 
Berdasarkan hasil penelitian ini, SPOONYCAL dapat memudahkan pengguna dalam mengontrol 
pola makan.
Kata Kunci : Kalori, deep learning, weight sensor

ABSTRACT
Alfino Almero Suroso dan Primafadhil Sulistyo “SPOONYCAL : Penghitung Kalori Berbasis Citra 
Makanan Menggunakan Internet of Things (IoT) dan Deep Learning”, Tugas Akhir DIII Program 
Studi Teknik Informatika, Jurusan Teknik Elektro, Politeknik Negeri Semarang, dibawah bimbingan 
Dr. Ir. Kurnianingsih, S.T., M.T. dan Angga Wahyu Wibowo, S.Kom., M.Eng September 2022.
Calories that enter the body, must be adjusted to daily needs. Lack of calories will cause the body to 
weaken and lower the body's immune level. Therefore, it is important to maintain calorie intake to 
minimize the risk of chronic disease. However, in doing this activity, many people still find it 
difficult to regulate the calorie intake that enters the body. SPOONYCAL is able to design a system 
to regulate food patterns in the community so that it is more controlled. In addition, the system can 
also calculate calories in food in terintegritas and on time. With the system design above the user 
can find out the number of calories eaten to minimize the occurrence of diseases caused by lack of 
calories in the body. In the system development process, a sequential method is used or commonly 
known as the waterfall method. From the needs analysis, it produces functional requirements which 
are described in use case diagrams and the results of system planning are described in activity 
diagrams and database modeling. In the process of making the system, the framework used is Flutter, 
the dart programming language, deep learning models, weight sensors, and also a mysql database for 
data storage. Based on the testing which includes black box testing, it shows that all the functionality 
of the system features are running well and based on the results of the questionnaire from 15
respondents consisting of managers and the community, the percentage of user satisfaction is 93,16% 
and it can be said that the system is very satisfying. Results Based on this study, SPOONYCAL can 
make it easier for users to control their eating patterns.

1.1. Latar Belakang
Kalori yang tepat berdampak sangat penting bagi kelangsungan hidup manusia. 
Kalori dapat dikontrol dengan pola makan yang teratur. Banyak masyarakat tidak 
memperhatikan pola makan, sehingga berdampak pada gangguan kesehatan. Kalori 
yang masuk ke dalam tubuh, harus disesuaikan dengan kebutuhan sehari - hari. 
Kekurangan kalori akan mengakibatkan tubuh lemas dan menurunkan tingkat imun 
tubuh. Di lain sisi, tubuh yang kelebihan kalori dapat menyebabkan penumpukan 
lemak pada tubuh sehingga meningkatkan risiko obesitas dan penyakit kronis 
lainnya (Henny Afika, 2021).
Jumlah angka obesitas di dunia mengalami peningkatan signifikan. Berdasarkan 
data Riskesdas (Tim Riskesdas 2018, 2019),sebesar 1,4% remaja mengalami 
kelebihan berat badan dan obesitas. Menurut penelitian Giuseppe (Grosso, 2021), 
kenaikan obesitas mencapai 5% selama pandemi pada tahun 2021. Hal tersebut 
disebabkan karena pola makan masyarakat yang kurang sehat, sehingga asupan 
kalori yang masuk pada tubuh tidak terkontrol. 
Berdasarkan permasalahan tersebut, diketahui bahwa pentingnya mengontrol kalori 
yang masuk pada tubuh agar dapat terhindar dari penyakit. Maka dari itu, penulis 
membuat SPOONYCAL yaitu sistem penghitung kalori berbasis citra makanan 
dengan memanfaatkan Internet of Things (IoT) dan Deep Learning. Sistem ini dapat 
membantu pengguna dalam menghitung jumlah rekomendasi asupan kalori harian 
berbasis aplikasi mobile. Sistem ini juga dapat memperingatkan pengguna apabila 
kalori yang dimakan melebihi batas kalori harian. 
1.2. Perumusan Masalah
Berdasarkan uraian latar belakang tersebut didapat pokok permasalahan yaitu 
terbatasnya pengadaan alat untuk menghitung kalori berbasis citra makanan. 
Sehingga dapat disimpulkan bahwa rumusan masalah utama pada Tugas Akhir ini 
adalah :
1) Bagaimana cara membuat suatu sistem yang dapat memberikan 
rekomendasi kalori harian ?
2
2) Bagaimana cara membuat sistem manajemen kalori pada makanan yang 
mudah digunakan oleh masyarakat ?
1.3. Tujuan
Tujuan pembuatan sistem ini adalah:
1) Merancang sistem untuk memperingatkan masyarakat dalam mengatur dan 
mengontrol jumlah asupan kalori yang dikonsumsi.
2) Merancang suatu sistem perhitungan kalori pada makanan secara personal
dan terintegritas.
1.4. Manfaat
Manfaat pembuatan sistem ini adalah :
1) Memberikan informasi kepada pengguna untuk mengetahui total kalori 
yang dimakan.
2) Meminimalisir terjadinya penyakit kronis dan obesitas yang diakibatkan 
oleh kelebihan kalori pada tubuh.
1.5. Batasan Masalah
Dalam pembuatan Tugas Akhir ini, masalah yang akan dibahas dibatasi oleh 
beberapa faktor, antara lain:
1) Pengguna harus menginputkan makanan agar dapat dihitung total kalorinya.
2) Alat dan sistem pendeteksi kalori makanan harus terkoneksi agar bisa
mendeteksi jumlah kalori yang masuk secara terintegritas.
3) Pengguna harus menunggu total kalori setelah makanan selesai dihitung 
semuanya.

2.1. Penelitian Terkait
Penelitian (Soebandi et al., 2020) pada tahun 2019, merancang sistem aplikasi 
perhitungan jumlah kebutuhan kalori harian berbasis mobile berdasarkan makanan 
yang dimakan setiap harinya. Pengguna akan dianalisis kebutuhan kalori hariannya 
berdasarkan tinggi, berat badan, dan usia. Setelah itu menginput data makanan yang 
dimakan secara manual ke aplikasi agar dapat dihitung jumlah kalori yang masuk.
Mochamad Dandi dkk (Dandi et al., 2021) pada tahun 2021, menerapkan metode 
CNN (Convolutional Neural Network) untuk menghitung nutrisi pada makanan 
berbasis android. Sistem tersebut memungkinkan pengguna untuk dapat 
mengetahui jumlah gizi, kalori, dan kalori melalui foto makanan. Tingkat akurasi 
yang dihasilkan sebesar 66%.
Penelitian yang dikembangkan oleh Teddy dkk (Santya et al., 2019) pada tahun 
2019, membuat sebuah sistem pakar dalam menentukan maksimal kalori harian 
berbasis mobile untuk memberikan peringatan kepada pengguna saat asupan yang 
dimakan melebihi batas kebutuhan, sehingga membantu orang - orang dalam 
menjaga kesehatan dengan mencegah penimbunan lemak dan gula pada tubuh.
P. Kamakshi Priyaa dkk (Kamakshi Priyaa et al., 2019) pada tahun 2019 
memberikan solusi sistem yang dikembangkan berbasis Internet of Things (IoT) 
menggunakan sensor berat dan pemancar sinyal untuk menyimpan asupan kalori 
yang didapatkan tubuh setiap harinya. Memanfaatkan arsitektur Arduino Uno 
sebagai basis alat, dan menggunakan Machine Learning untuk menganalisis data 
yang didapatkan. Alat tersebut akan menghitung berat makanan yang akan 
dimakan, lalu mengirimkan data yang didapat oleh sensor menuju cloud untuk 
diolah lebih lanjut agar dapat ditampilkan di aplikasi mobile.
5
Mengkombinasikannya dengan metode Convutional Neural Network (CNN) agar 
dapat mengidentifikasi makanan berdasarkan foto, lalu mengkalkulasikannya 
terhadap berat makanan tersebut.
Isaac dkk (Machorro-Cano et al., 2019) melakukan pembuatan sistem yang 
bernama PISIoT. PISIoT merupakan Smart Health Platform yang berguna untuk 
mengontrol penyakit Obesitas dan berat badan berlebih berbasis Machine Learning
dan Internet of Things (IoT). Berat badan pengguna akan dijadikan sebagai 
parameter utama, lalu diproses menuju aplikasi berbasis website dan mobile. 
Berdasarkan hasil tersebut, nantinya dapat digunakan sebagai pengontrol kalori 
yang masuk ke dalam tubuh pengguna.
Penelitian (Mbarushimana et al., 2021) pada tahun 2021, mengemukakan bahwa 
asupan kalori yang diterima tubuh sangat berpengaruh terhadap bentuk badan dan 
kondisi imun seseorang. Berdasarkan uji sampel dari berbagai jenis kelamin dan 
usia, menunjukkan bahwa orang yang memiliki asupan kalori di bawah standar 
normal cenderung mudah terkena penyakit.
Anggraeni dkk (Anggraeni et al., 2018) pada tahun 2018 mengembangkan sebuah 
sistem yang dapat membantu menurunkan berat badan seseorang berbasis aplikasi 
berbasis Android. Aplikasi akan membaca berat badan pengguna, lalu 
dikalkulasikan berdasarkan tinggi badan, umur, dan jenis kelamin supaya dapat 
menampilkan total kebutuhan kalori harian pengguna.
Penelitian yang dilakukan oleh Indra dkk (Sucipta et al., 2021) menciptakan sebuah 
prototipe guna memantau tetes cairan infus berbasis Internet of Things (IoT) yang 
dapat terkoneksi dengan perangkat Android. Mikrokontroler yang digunakan 
merupakan ESP32 dengan Sensor Optocoupler yang dapat mengontrol jalannya 
arus cairan dari selang infus.
Laavanya dkk (Rachakonda et al., 2019) membuat sebuah sistem berbasis Internet 
of Things untuk membantu memantau kecenderungan dalam memakan makanan 
atau dapat disebut Stress Eating. Sistem tersebut dapat mendeteksi makanan apa

saja yang dimakan oleh pengguna, lalu diproses terhadap total kebutuhan kalori 
menggunakan Object Detection.
Penelitian yang dilakukan oleh (Mrs.D.Siva Senthil, 2021) mengembangkan sebuah 
sistem berbasis Internet of Things (IoT) untuk menghitung kalori berdasarkan 
makanan yang dapat disimpan pada aplikasi Android. Sistem tersebut juga dapat 
melihat kalori pada makanan dengan memindai barcode pada kemasan, lalu 
memunculkan pop up total kalori pada makanan tersebut.
Berdasarkan uraian tersebut yang membahas beberapa penelitian seputar 
pengaplikasian Internet of Things dan Deep Learning pada bidang kesehatan yang 
telah dilakukan oleh para peneliti, belum terdapat sebuah sistem yang dapat

kalori harian untuk mencegah terjadinya penumpukan lemak dan meminimalisir

2.2. Teknologi yang Digunakan
Pada bagian ini membahas tentang teknologi yang digunakan dalam 
mengembangkan sistem SPOONYCAL : Penghitung Kalori Berbasis Citra 
Makanan yang diantaranya sebagai berikut.
2.2.1. Python
Python merupakan bahasa pemrograman yang ditafsirkan tingkat tinggi, yang 
dikenal luas karena mudah dipelajari, namun mampu memanfaatkan kekuatan 
tingkat sistem bahasa pemrograman bila diperlukan. Python dan ekosistem 
pendukungnya menciptakan kelayakan pembelajaran yang mendalam, serta 
kebutuhan infrastruktur cloud dan solusi pemrosesan data skalabel yang mampu 
menangani volume data, yang memungkinkan alur kerja yang dulunya sulit 
diselesaikan dalam waktu yang wajar.(Raschka et al., 2020). Pada sistem ini Python 
digunakan untuk bahasa pemrograman utama pada proses deep learning.
2.2.2. Flutter
Flutter merupakan framework UI mobile terbuka dan gratis yang dibuat oleh 
Google dan dirilis pada Mei 2017. Singkatnya, ini memungkinkan pengguna 
membuat aplikasi mobile asli hanya dengan satu basis kode. Dengan ini, pengguna 
dapat menggunakan satu bahasa pemrograman dan satu basis kode untuk membuat 
dua aplikasi berbeda (untuk iOS dan Android). Flutter terdiri dari dua bagian 
penting, yaitu SDK (Software Development Kit) untuk membantu mengembangkan 
aplikasi dan Framework untuk menggunakan fungsi pengulangan sesuai kebutuhan 
pengguna. (Thomas, 2019). Pada sistem ini Flutter digunakan sebagai framework 
utama dalam pembuatan aplikasi mobile.
2.2.3. Dart
Dart merupakan sebuah bahasa pemrograman yang dikembangkan oleh Google dan 
merupakan bahasa pemrograman resmi buat Flutter, sebuah UI toolkit dan software
multiplatform asal Google. Penggunaan bahasa Dart itu gratis (open source) dan 
dikembangkan oleh komunitas developer pakar yang aktif dan terbuka. (Hanif & 
9
Sinambela, 2021). Pada sistem ini dart digunakan sebagai bahasa utama dalam 
pengembangan UI pada mobile.
2.2.4. MySQL
MySQL adalah DBMS yang terbuka dengan dua bentuk lisensi, yaitu free software 
program (perangkat lunak bebas) dan Shareware (perangkat lunak berpemilik yang 
penggunaannya terbatas). Jadi MySQL adalah database server yang free of charge 
dengan lisensi GNU preferred Public License (GPL) sehingga dapat Anda pakai 
untuk keperluan pribadi atau komersil tanpa harus membayar lisensi yang ada. 
MySQL memakai bahasa SQL menjadi bahasa penghubung antara software 
aplikasi dengan database server.(Jantce et al., 2020). Pada sistem ini MySQL 
digunakan sebagai database utama.
2.2.5. Figma
Figma dapat memudahkan kerja sama antar tim pada proses menghasilkan, 
menguji, dan mengirim desain jadi lebih praktis. Penyimpanan dari pekerjaan figma 
berbasis cloud, jadi dapat tersimpan secara online.(Ferdi et al., 2021). Pada sistem 
ini, Figma digunakan untuk merancang desain aplikasi Spoonycal Mobile. 
2.2.6. Deep Learning
Deep Learning merupakan cabang yang berasal dari Machine Learning, terinspirasi 
berasal dari manusia dengan menerapkan jaringan syaraf buatan yang mempunyai 
banyak hidden layer. Salah satu library jaringan syaraf buatan yang terdapat pada 
Deep Learning ini adalah Keras. Keras merupakan library jaringan syaraf tiruan 
tingkat tinggi yang ditulis dengan bahasa python dan mampu berjalan di atas CNN, 
TensorFlow, CNTK, atau Theano.(Santoso, 2018). Pada sistem ini, Library yang 
digunakan pada Deep Learning yaitu Keras dengan model CNN untuk melakukan 
Image Classification.
2.2.7. Image Classification
Image Classification atau Klasifikasi Gambar (sering disebut sebagai Pengenalan 
Gambar) merupakan tugas untuk mengasosiasikan satu (klasifikasi label tunggal) 
atau lebih (klasifikasi multi-label) ke gambar tertentu. Image Classification
memiliki tugas yang solid untuk membandingkan arsitektur dan metodologi modern 
10
dalam domain visi komputer. (Bandyopadhyay, 2022). Pada sistem ini, Image 
Classification digunakan sebagai pratinjau total kalori pada makanan setiap 100 
gramnya.
2.2.8. Convolutional Neural Network (CNN)
Convolutional Neural Network CNN memiliki banyak lapisan; termasuk lapisan 
convolutional, lapisan non-linier, lapisan pooling serta lapisan yg terhubung penuh. 
Lapisan convolutional dan sepenuhnya terhubung memiliki parameter tetapi lapisan 
penyatuan serta non-linier tidak mempunyai parameter. CNN mempunyai kinerja 
yg sangat baik dalam dilema pembelajaran mesin (Albawi et al., 2017). Pada sistem 
ini, Convolutional Neural Network digunakan sebagai model dari Image 
Classification. 
2.2.9. Webview
Webview digunakan sebagai perantara untuk menampilkan website pada aplikasi 
mobile. Halaman web yang ditampilkan akan diambil menggunakan URL (Uniform 
Resource Locator). Disamping itu, untuk menggunakan Webview, pengguna juga 
memerlukan koneksi internet agar dapat menampilkan dan berinteraksi dengan 
website.
2.2.10.IoT (Internet of Things)
Rangkaian yang menghubungkan berbagai objek dan komponen yang memiliki 
kemampuan untuk mengendalikan, komunikasi, kerja sama antar hardware
maupun software melalui jaringan internet yang sering disebut dengan (Internet of 
Things). IoT memungkinkan untuk membaca maupun mengirim suatu I/O (Input / 
Output) melalui koneksi internet tanpa bantuan komputer dan manusia.

pengguna dalam membangun aplikasi mobile.

2.2.16.Load Cell Sensor
Load Cell Sensor merupakan sensor untuk menghitung berat yang disusun 
berdasarkan strain gauge, konduktor, dan jembatan wheatstone (Wahyudi Wahyudi 
et al., 2017). Load Cell Sensor menghitung massa benda yang terdapat pada gauge, 
lalu meneruskannya menuju modul selanjutnya. Berikut merupakan spesifikasi 
Load Cell Sensor;
● Vsuplai : max DC 10V.
● Beban : max 5000 gr (5 Kg)
● Output : 0,1 mV ~ 1,0 mV / V (skala 1:1000 terhadap tegangan masukan, 
margin error ≤1,5%)
● Suhu operasional : -20 ~ +65°C.
● Bahan : Aluminium alloy.
● Dimensi : 8 cm x 1,25 cm x 1, 25 cm.
● Berat : 30 gr.
2.2.17.HX711 Module
Modul HX711 merupakan modul amplifier yang biasa digunakan pada rangkaian 
timbangan digital menjadi modul konversi frekuensi analog ke digital pada load 
cell (Varshitha et al., 2021). Berikut merupakan spesifikasi HX711 module;
● Voltase : DC 5V.
● Arus : 10 mA.
● Input : 2 channel Analog dari load cell (bisa dipakai untuk 2 load cell)
13
● Output : TTL (serial tersinkronisasi, DI dan SCK)
● Akurasi data : 24 bit (24-bit ADC)
● Frekuensi pembacaan (refresh rate) : 80 Hz.
● Dimensi : panjang 38 mm x lebar 21 mm.
● Berat : 20 gr
2.2.18.Kabel Jumper
Kabel Jumper merupakan kabel yang digunakan untuk menghubungkan komponen 
dengan komponen lain pada mikrokontroler. Kabel ini dapat digunakan juga 
sebagai penghubung jalur rangkaian yang terputus maupun sarana pengiriman arus 
menuju suatu komponen.

Rechargeable Battery 18650 merupakan salah satu jenis baterai yang memiliki fitur 
dapat diisi ulang atau rechargeable. Baterai jenis ini memiliki arsitektur sama 
seperti baterai Lithium-Ion dengan siklus hidup lebih baik. Berikut spesifikasi 
Rechargeable Battery 18650 yang digunakan;
● Voltase : 3.6V.
● Kapasitas : 2,850 mAh.
● Voltase Pengisian Daya : 4.2V
● Durasi Pengisian Daya : 3 jam 
● Metode Pengisian Daya: CC and CV.
2.2.20.18650 Battery Shield
Sebuah shield yang berfungsi untuk membantu memasok sumber menuju

● Jenis Kabel : USB Type-A.
● Voltase Pengisian Daya : 5 - 8V.
● Jumlah Port: 3x 3V dan 3x 5V.

3) Implementing and Unit Testing
Pada tahap ini, perancangan sistem direalisasikan pada program atau unit program

dibuat.
4) Integration and System Testing
Unit program maupun program yang terpisah diintegrasikan dan diuji menjadi 
kesatuan sistem untuk memastikan bahwa kebutuhan dari perangkat lunak tersebut 
sudah dipenuhi. Sesudah proses integrasi selesai, selanjutnya dilakukan 
pemeriksaan dan pengujian sistem secara keseluruhan untuk pengidentifikasian 
kemungkinan adanya kegagalan serta kesalahan sistem.
5) Operation and Maintenance
Umumnya, termin ini artinya termin terpanjang dari SDLC sebab sistem diinstal

kesalahan atau error, perbaikan implementasi unit sistem, peningkatan serta 
penyesuaian sistem sesuai dengan kebutuhan.

3.2.6. Perancangan Model Deep Learning

Gambar 3.39 Arsitektur Resnet50
Model Resnet50 tersebut dikembangkan oleh tim mmdet. Berbasis Convulotional 
Neural Network (CNN) yang memproses pixel pada foto yang dimasukkan 
pengguna melalui Spoonycal Mobile dan ditampilkan hasil dari proses pengolahan 
citra. Dataset yang digunakan dalam perancangan model sebanyak 127 gambar 
dengan pembagian 111 gambar sebagai train, 6 gambar sebagai validation, dan 10 
gambar sebagai test. Ketika melakukan tahap pre-processing dan augmentation 
pada dataset menggunakan bantuan Roboflow. Prosedur preprcessing data pada 
SPOONYCAL dapat dilihat pada Gambar 3.40.

4.1. Analisis Sistem
Pada bagian ini berisi pembahasan serta analisis aplikasi android Spoonycal Mobile
dan alat SPOONYCAL. Aplikasi android ini dibangun menggunakan framework 
Flutter dan dibantu dengan MySQL sebagai tempat datanya atau database nya yang 
dibuat menggunakan bahasa pemrograman PHP dengan framework Laravel. Kedua 
platform terhubung menggunakan REST API (Representional State Transfer 
Application Programming Interface) yang memungkinkan antar platform untuk 
mengirimkan data satu sama lain. REST merupakan metode komunikasi 
menggunakan protokol HTTP untuk pertukaran data dan sering digunakan pada 
pengembangan aplikasi. REST API ini di-deploy menggunakan bantuan website 
Heroku dengan layanan Free.
Pengkalibrasian pada sensor - sensor dalam alat Internet of Things (IoT) dilakukan 
dengan membandingkan hasil output keluaran berdasarkan nilai real oleh alat ukur 
sesuai standar pengukuran. Hal tersebut dilakukan untuk mengetahui akurasi dari 
hasil pembacaan data dengan nilai sebenarnya. 
4.1.1. REST API
Proses request API pada sistem ini yaitu setelah server menerima permintaan yang 
benar dan telah valid, maka server akan memproses permintaan menghubungkan 
dengan database Heroku. REST API pada aplikasi terdapat beberapa poin berikut.
1) URL Endpoint
Setiap request data dengan API pada aplikasi ini membutuhkan suatu URL. 
Permintaan request API diakses melalui alamat URL https://Spoonycal￾ta.herokuapp.com/api/(route).
57
2) HTTP Verb
Setiap request yang dilakukan, terdapat sebuah method atau verbs yang digunakan 
untuk menjelaskan maksud request yang diberikan. Pada aplikasi ini menggunakan 
GET untuk membaca dan mendapatkan data dan POST untuk membuat serta 
memperbarui data.
3) Response
Jika sistem berhasil memvalidasi permintaan yang masuk, maka
sistem akan mengembalikan permintaan yang dibutuhkan. Output Response yang 
dihasilkan berupa format JSON. Contoh response dari permintaan yang valid 
ditampilkan seperti gambar 4.1.
